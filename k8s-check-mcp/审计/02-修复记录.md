## Bug 修复

### 1. Init Container 资源计算错误 ✅

**修改内容：** 新增 `_max_container_resources()` 函数，对 init containers 按 K8s 调度语义取每个 container 在各资源维度（CPU request/limit、Memory request/limit）上的**最大值**，而非之前错误的求和。

**修改位置：**
- 新增函数 `_max_container_resources()`（line 543-557）
- `_pod_effective_resources()` 中将 `_sum_container_resources(init_containers)` 改为 `_max_container_resources(init_containers)`（line 571）

```python
# 修复前：对 init containers 求和（错误）
i_req_cpu, i_lim_cpu, i_req_mem, i_lim_mem = _sum_container_resources(init_containers)

# 修复后：取每个 init container 各资源维度的最大值（符合 K8s 调度语义）
i_req_cpu, i_lim_cpu, i_req_mem, i_lim_mem = _max_container_resources(init_containers)
```

### 10. 缺少健康检查机制 ✅

**修改内容：** 新增 `health_check` MCP tool，验证 K8s API 连通性。

**修改位置：** 新增 tool 函数（line 1166-1187），同步更新 `cluster_summary` 的 `available_tools` 列表

```python
@mcp.tool(...)
def health_check() -> dict[str, Any]:
    """验证 MCP Server 与 K8s API 的连接状态。"""
    try:
        kube = _get_k8s_clients()
        nodes = _k8s_api_call(kube.core.list_node)
        return {"status": "healthy", "cluster": kube.display_name, ...}
    except Exception as e:
        logger.warning("Health check failed: %s", e)
        return {"status": "unhealthy", "error": str(e)}
```
